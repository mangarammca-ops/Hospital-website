# Hospital Website

Ye ek hospital ki website hai jahan patients hospital ke baare mein jaankari dekh sakte hain, doctors ki list dekh sakte hain aur appointment book karne ke liye contact kar sakte hain.

## Features
- Home page with hospital ki overview
- Departments / Services ki list (Cardiology, Orthopedic, Pediatrics etc.)
- Doctors ka section (naam, specialization, timing)
- Appointment booking form
- Contact page with address aur phone number
- Responsive design (mobile aur laptop dono par chalti hai)

## Technologies Used
- HTML
- CSS
- JavaScript
