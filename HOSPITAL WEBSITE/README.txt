JAIMAL HOSPITAL WEBSITE (HTML + CSS + JavaScript)

Files:
- index.html : page structure
- style.css  : design + responsive layout
- script.js  : doctor data, OPD schedule, slot booking, facilities, packages
- images/    : section illustrations (SVG)

How to open: extract the ZIP, double-click index.html. Keep all files and the images folder together.

Put YOUR photos here (optional, they appear automatically):
- images/hospital-hero.png  -> hero background (optional)
- Doctor photos are images/dr-<name>.jpg and are set in script.js (photo: ...).

How to edit:
- Doctors, days and timings: top of script.js (the "doctors" list, "sessions" = days + from/to time).
  Schedule table, today's OPD list, doctor cards and booking slots all update automatically.
- Facilities / health packages / testimonials: "facilities", "packages", "testimonials" in script.js.
- Phone, email, address: index.html.

IMPORTANT: Demo only. Doctor names, fees, timings, phone and email are SAMPLE details.
Bookings are saved only in the visitor's own browser (localStorage). Connect a secure backend
before real use. Do not use for real medical or emergency requests.
